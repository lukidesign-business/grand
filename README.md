# Grand Property

A bilingual (EN/PL) premium property-investment site for Pattaya, Thailand.

**Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui conventions · lucide-react**

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run typecheck  # tsc --noEmit
```

## Using this with v0.dev

The project follows the layout v0 expects, so you can point it at the repo and
iterate on components directly:

- `components.json` — shadcn/ui config (new-york, RSC, lucide, `@/` aliases)
- `@/` path alias, `lib/utils.ts` exporting `cn()`
- Tailwind v4 with tokens in `app/globals.css` under `@theme inline` — no
  `tailwind.config.js`
- `components/ui/*` for primitives, `components/*` for composed sections
- Server components by default; `'use client'` only where there is state

**Design tokens are the thing to know.** Colours are Tailwind utilities, not hex
literals: `bg-ink`, `bg-surface`, `text-gold`, `text-gold-bright`, `text-cream`,
`text-muted`, `border-line`, `border-line-strong`. Type is `font-serif`
(Cormorant Garamond) and `font-sans` (Jost). There are custom utilities for the
repeated luxury patterns: `shell`, `section-y`, `rule-gold`, `text-gradient-gold`,
`hero-scrim`, `page-scrim`, `section-wash`. Ask v0 to use these rather than raw
values and new sections will match the rest of the site.

Adding a shadcn component works normally: `npx shadcn@latest add dialog`.

## Routing and language

Every route is built for both locales, so `/en/<path>` and `/pl/<path>` mirror
each other. The language switcher is a pure prefix swap and `hreflang` sets are
generated by `alternatesFor()` in `lib/metadata.ts`.

`middleware.ts` sends a locale-less request to the right place, in order:

1. the `gp-lang` cookie (a previous explicit choice)
2. `x-vercel-ip-country` — the CDN's location hint, mapped in `localeByCountry`
3. `Accept-Language`
4. English

First-time visitors also see a language panel (`components/language-gate.tsx`)
offering both options. It is a real modal — labelled, focus-trapped, Escape to
close, focus restored — and writes the same cookie, so middleware honours the
choice on every later visit.

## Editing content

All copy is in `lib/i18n/en.json` and `lib/i18n/pl.json`. The English file is the
source of truth for the dictionary type, so a key added there surfaces as a
TypeScript error until it exists in Polish too.

Project prose is keyed by project id under `projects.items`; the structural facts
(price, plan, bedrooms, images) live in `lib/site.ts` so they stay identical
across languages. `{n}` is a count placeholder — counters carry separate singular
and plural strings (`resultCount` / `resultCountOne`) because Polish needs them.

## Images

`public/images` totals roughly 1.5 MB and every file is already compressed to its
display size. Section imagery uses `next/image`; the `wash-*.jpg` files are
deliberately soft, low-quality copies used as very low opacity section textures.

Two deliberate exceptions:

- The hero uses a plain `<picture>` rather than `next/image`, because it is
  art-directed (wide crop on desktop, portrait crop under 768px). Two `<Image>`s
  toggled with CSS would download both on every device.
- `next.config.mjs` caps `deviceSizes` at 1920. The source art tops out near
  1600px wide, so the 2048/3840 breakpoints only ever produced upscaled files.

To re-encode from the originals, run the PowerShell scripts in `tools/`
(`optimise-images.ps1`, `prep-logo.ps1`); sources are in `tools/source-images`.

## Before launch

- **Contact details are placeholders.** Replace `email`, `phoneDisplay`,
  `phoneHref`, `whatsappHref` and `social` in `lib/site.ts`, then remove
  `footer.placeholderNote` from both locale files.
- **The contact form has no backend.** `components/contact-form.tsx` validates
  and acknowledges locally. Replace the `setTimeout` with a server action or a
  route handler.
- **Set `NEXT_PUBLIC_SITE_URL`** so `sitemap.xml`, `robots.txt`, canonicals and
  Open Graph URLs are absolute.
- Deploy to Vercel as-is; the country-based locale hint uses a Vercel header and
  degrades to `Accept-Language` elsewhere.

## Notes

- Reveal-on-scroll (`components/reveal-on-scroll.tsx`) is a position sweep, not
  an `IntersectionObserver`. Deep links, restored scroll positions, backgrounded
  tabs and fast scrolling can all skip an observer callback and strand content at
  `opacity: 0`; a sweep cannot miss. It re-runs on route change and honours
  `prefers-reduced-motion`.
- The hero search bar is a plain GET form, so it works without JavaScript and
  hands its query to the search page, which seeds its filter state from the URL.
- The static HTML version this was ported from is preserved at
  `../grand-properties-static-backup` and can be deleted once you are happy.
